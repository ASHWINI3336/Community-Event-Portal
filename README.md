# Community Event Management Portal

A simple and interactive frontend web application designed to help users discover local community events, register for them, and manage their registrations online.

## 🚀 Features

- **Event Discovery**: Browse upcoming events like Music Festivals, Tree Plantation drives, Blood Donation Camps, and Coding Competitions.
- **Search Functionality**: Instantly search for specific events by name.
- **Registration System**: Easily register for events directly from the portal.
- **Manage Registrations**: View a list of your upcoming event registrations.
- **Responsive Design**: Clean and modern UI for an optimal viewing experience.

## 🛠️ Technologies Used

- **HTML5**: For structuring the content.
- **CSS3**: For styling and layout (responsive design).
- **Vanilla JavaScript**: For search functionality and dynamic event registration handling.

## 📁 Project Structure

```text
Community-Event-Portal/
├── style.html   # Main HTML structure
├── style.css    # Styling and layout
└── style.js     # Logic for searching and registering for events
```

## ⚙️ How to Run Locally

1. Clone the repository:
   ```bash
   git clone https://github.com/ASHWINI3336/Community-Event-Portal.git
   ```
2. Navigate to the project directory:
   ```bash
   cd Community-Event-Portal
   ```
3. Open `style.html` in your web browser, or use a local development server like Live Server (VS Code) or Python's HTTP server:
   ```bash
   python -m http.server 8080
   ```
   Then visit `http://localhost:8080/style.html`.
